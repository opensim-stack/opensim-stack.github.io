Play It

Log in and start giving instructions to your AI bot.

1 Log In

Once the stack is running, open your OpenSimulator viewer and add a new grid:

Grid Login URI

http://<OPENSIM_HOSTNAME>:9000

Replace with your actual hostname or IP.

Default Credentials

First: Bot

Last: Handler

Password: changeme

These are defaults from .env.example. Change them before exposing your grid to the internet.

After logging in you should arrive at Welcome Island (or whatever you named your region). Look around — the bot avatar should be nearby.

2 Talk to the Bot

The bot is configured to accept instant messages from the estate owner by default. Right-click the bot avatar and start an IM conversation, then try a simple instruction:

Place a cube prim 2 meters away and scale it x2.

The bot can also:

  • ▸ Walk, run, fly, or teleport
  • ▸ Create and edit prims
  • ▸ Manage inventory and assets
  • ▸ Upload media
  • ▸ Configure environment settings
  • ▸ Run console commands
  • ▸ And lots, lots, more.

3 Get Some Content

Your grid starts with a Sandbox by Bwild Parx : Sandbox-0 by ACME Prims, but there is a huge library of free and paid OpenSimulator content available online. You can import whole regions, avatars, clothing, textures, buildings, and more as OAR and IAR files.

  • ▸ OutWorldz — Freeregions, textures, mesh objects
  • ▸ Zadaroo — free/paid avatars, clothing, and more
  • ▸ OpenSim World — region directory and free OARs
  • ▸ TurboSquid — paid 3D models and meshes
  • ▸ CGTrader — 3D assets for buildings and avatars
Just give the bot the URL of what you want to download, or place it yourself in /workspace. The example below uses Tropical by Linda Kellie 
Import the OAR "https://opensim-stack.github.io/OAR-Tropical(1X1).tgz"
and load it into this region.

4 Switch AI Provider

The default provider is Opencode Zen with free models. When you start hitting limits, or want access to better models, we recommend you upgrade to a paid account. If you are just starting, Opencode Go would be a good choice. $5 for a month, then $10 a month thereafter at the time of writing. Use *models, *providers and *configure commands to switch between providers and models. 

*auth opencode api 23k2345jksd80923509sdf0893245  # Replace with your actual API key
*configure opencode/gpt-5.3-codex

Or switch to opencode-go

*auth opencode-go api 23k2345jksd80923509sdf0893245  # Replace with your actual API key
*configure opencode-go/qwen3.7-plus

Or switch to a completely different provide like Github Copilot. which uses OAuth to authenticate:

*auth methods github-copilot
*auth github-copilot oauth 0     # Then follow the link to authenticate
*auth github-copilot oauth-complete 0
*configure github-copilot/gpt-5.3-codex
For more providers and star commands, see the Docs.
