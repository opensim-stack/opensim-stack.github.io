# opensim-stack.github.io

Static website for the [OpenSim AI Stack](https://github.com/opensim-stack/opensim-ai-docker) — a Docker-based OpenSimulator grid with AI integration.

## Pages

- **Home** — hero, features, and stack overview
- **Get It** — prerequisites, Docker Compose commands, and key environment variables
- **Play It** — login instructions and how to talk to the AI bot
- **Share It** — ports to open and hypergrid basics

## Tech

- Tailwind CSS v4 (CDN)
- DaisyUI v5 (CDN)
- Vanilla HTML/JS
- GitHub Pages ready

## Local preview

Any static file server works, for example:

```bash
python3 -m http.server 8000
```

Then open <http://localhost:8000>.
