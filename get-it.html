Get It

Deploy your AI-enabled OpenSimulator grid in minutes.

1 Prerequisites

Operating System

You need a modern operating system that supports Docker. Linux, Mac OS or Windows with WSL2 are supported.

Linux
Mac OS
Windows

Docker Compose

You need Docker Engine and Docker Compose v2 (docker compose) installed.

Docker

OpenSimulator Viewer

A viewer is how you log in to your grid. We recommend Firestorm, but any compatible viewer works.

Firestorm Singularity Cool VL
Most of the stack is multi-architecture and will work on intel or arm processors. However, there are some exceptions. See Docs.

2 Compose

One Line Install. This pipes the latest docker compose file directly to your local docker instance.

curl https://opensim-stack.github.io/docker-compose.yml | \
OPENSIM_HOSTNAME=$(hostname) docker compose -f - up -d
Check the output of hostname command, that is the name you will use to connect to the grid and web UI.
View docker-compose.yml View .env.example

3 Configure Your Grid

OpenSim AI Stack now includes a purpose built web user interface with an easy Setup Wizard. Point your browser at http://yourhostname:8993 to complete setting up your grid.

See Docs for other ways to install.
